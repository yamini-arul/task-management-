# Task Manager

A simple and efficient Task Management Web Application built with Node.js and Express.js. This application allows users to create, update, delete, and manage tasks through a user-friendly interface.

## Features

* Create new tasks
* View all tasks
* Update existing tasks
* Delete tasks
* Simple and responsive user interface
* RESTful architecture
* Lightweight and easy to use

## Technologies Used

* Node.js
* Express.js
* HTML
* CSS
* JavaScript

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/task-manager.git
```

2. Navigate to the project directory:

```bash
cd task-manager
```

3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm start
```

or

```bash
node server.js
```

5. Open your browser and visit:

```text
http://localhost:3000
```

## Usage

1. Add new tasks.
2. Edit task details when required.
3. Mark tasks as completed.
4. Delete tasks that are no longer needed.
